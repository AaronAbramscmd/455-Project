RefMatch: Match & Party Booking System Overhaul
 * This repository contains the completely overhauled web application designed to streamline party bookings and referee match assignments.
 * Built from scratch using a modern procedural stack, it replaces our legacy system with a database-driven, responsive platform.

For Users
 * Dynamic Booking: Browse and instantly book a party.
 * Self-Service Cancellation: Easily remove or cancel an existing booking directly from the dashboard.
 * Real-Time Availability: Prevent double-booking with instant MySQL state validation.

For RefereesPick & Choose: 
  * View a live marketplace of upcoming unassigned parties and matches.
  * Self-Assignment: Claim specific parties or matches based on personal availability and preference.
  * Schedule Overview: Access a personalized dashboard showing all currently claimed assignments.
